demos

Eight possible looks for this site, all using the same four projects. Clicking a project in any of them takes you to the real, locked page.

  1. Rooms — one full screen per project, each in its own colors
  2. Broken — Rooms, roughed up: cropped giant titles, images spilling between rooms
  3. Type — full-bleed images with huge plain titles across them
  4. Lines — every image floating on pale grey, joined by one thin line
  5. Index — the current site, tightened up
  6. Frames — a list on the left, one project at a time on the right
  7. Table — the whole slate as one table
  8. README — everything as a text file, with pictures
